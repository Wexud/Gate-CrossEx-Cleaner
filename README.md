## Перед початком

Потрібні Windows 10/11 та ваші **Gate CrossEx API Key і API Secret**. Python та додаткові бібліотеки не потрібні. Для перевірки балансів потрібні права читання; для обміну й внутрішнього переказу — відповідні права CrossEx. Право виведення на зовнішні адреси цьому скрипту не потрібне.

Для повного режиму акаунт має працювати в режимі `CROSS_EXCHANGE`, без відкритих ордерів, активних ф'ючерсних/маржинальних позицій і боргів. **На час роботи вимкніть інші боти та не торгуйте й не переказуйте кошти на цьому акаунті.**

API Secret вводиться тільки у вікні програми. Нікому його не надсилайте, не вставляйте в код, GitHub або скріншоти. Скрипт сам не записує ключі у файли. Права адміністратора для його роботи не потрібні.

## Крок 1. Завантажте та розпакуйте

На початку цієї сторінки натисніть **«Завантажити Gate CrossEx Cleaner v1.0.5 (ZIP)»**.

Після завантаження у Провіднику натисніть правою кнопкою на ZIP і виберіть **Видобути все / Extract All**.

Відкрийте розпаковану папку. Зайдіть усередину вкладеної папки, якщо вона є. Ви повинні бачити саме файл:

```text
gate_crossex_cleaner.ps1
```

Не запускайте скрипт прямо з вікна ZIP-архіву. Назва папки може містити `Gate-CrossEx-Cleaner-1.0.5` — перейменовувати її не потрібно.

## Крок 2. Відкрийте PowerShell у цій папці

1. У Провіднику відкрийте папку, де видно `gate_crossex_cleaner.ps1`.
2. Натисніть **Alt+D**, щоб виділити адресний рядок угорі.
3. Введіть **саме з розширенням `.exe`**:

```text
powershell.exe
```

4. Натисніть **Enter**. Має відкритися вікно PowerShell, а не інша папка Провідника. Якщо у списку підказок показано `powershell.exe`, можна вибрати саме цю програму.

> Не вводьте просто `powershell`: Провідник може відкрити папку `Документи\PowerShell` замість програми.

У відкритому PowerShell вставте команду та натисніть Enter:

```powershell
Test-Path -LiteralPath .\gate_crossex_cleaner.ps1
```

Має з'явитися **True**. Якщо бачите **False**, не переходьте далі: поверніться до папки з файлом і повторіть цей крок. Напис `PS C:\Windows\System32>` зазвичай означає, що ви відкрили не ту папку.

## Крок 3. Перевірте баланс без обміну

Скопіюйте у PowerShell **один рядок повністю**:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\gate_crossex_cleaner.ps1 -BalancesOnly
```

Після кожного введення натискайте Enter:

```text
Gate CrossEx API Key:
Gate CrossEx API Secret (hidden):
```

Спочатку вставте API Key, потім API Secret. Secret буде прихований або показаний зірочками — це нормально. Не вписуйте ключі замість частин команди запуску.

Після цього побачите ненульові залишки, наприклад:

```text
HYPERLIQUID   USDC   balance=12.23  available=12.23  liability=0
CROSSEX       USDT   balance=5     available=5      liability=0
```

**`-BalancesOnly` нічого не обмінює та не переводить.** Слово `available` означає доступну суму. Порожній список означає відсутність ненульових залишків у отриманій відповіді.

Якщо з'явилася помилка, не переходьте до наступного кроку. Успішна перевірка балансу підтверджує доступ до читання, але сама по собі не перевіряє можливість обміну чи переказу.

## Крок 4. Запустіть обмін і переказ

У тому самому вікні виконайте команду **без `-BalancesOnly`**:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\gate_crossex_cleaner.ps1
```

Знову введіть API Key та API Secret. Скрипт перевірить акаунт, позиції, ордери й борги. Якщо перевірка не пройде, подальші фінансові дії не виконуються.

Далі будуть окремі підтвердження. Читайте суму та повідомлення перед кожним `YES`.

### 4.1. Перегляд пропозицій обміну

```text
Request preview quotes now? Type YES
```

Введіть великими латинськими літерами **YES** і натисніть Enter. Це лише запит, скільки USDT Gate запропонує за кожен актив; сам обмін ще не відбувається.

```text
HYPERLIQUID USDC 12.23 -> 12.20 USDT
```

Суми у вас будуть інші. Пропущені активи позначаються `SKIP`.

### 4.2. Реальний обмін

```text
Execute accepted Flash Swaps? Type YES
```

Перевірте показані пропозиції. Для обміну введіть **YES**. Цим ви дозволяєте обмін перелічених активів у показаних кількостях із налаштованими обмеженнями ціни.

Перед кожним обміном береться нова пропозиція Gate. Якщо вона надто погіршилася — актив буде пропущений. Якщо доступна кількість змінилася після вашого підтвердження, скрипт зупиниться, а не обмінюватиме іншу суму.

За замовчуванням допустиме погіршення нового курсу відносно показаного — **1%**. Для USDC і USD додатково допускається не більше **1%** втрати від співвідношення 1:1 до USDT.

**Ліміт 1% від попередньої пропозиції не означає, що загальний спред або відхилення від ринкової ціни не перевищує 1%.** Для BTC, ETH та інших нестабільних активів незалежна ринкова ціна не перевіряється. Оцініть показану суму самостійно перед підтвердженням.

Після прийняття обміну скрипт чекає, щоб списання вихідного активу та зарахування CROSSEX USDT відповідали сумам котирування. Неповний або незрозумілий результат зупиняє подальші фінансові дії.

### 4.3. Переказ USDT на Spot

Програма покаже суму внутрішнього переказу, орієнтовну комісію та орієнтовне зарахування. Потім запитає, наприклад:

```text
Transfer 17.20 USDT to SPOT? Type YES
```

Після **YES** виконується переказ **з вашого CrossEx на ваш Gate Spot**. У суму входять також USDT, які вже були в `CROSSEX` до запуску, а не лише результат нових обмінів.

Після підтвердження сума, параметри переказу та стан акаунта перевіряються ще раз. Якщо щось змінилося, переказ не відправляється.

Підтверджений успіх:

```text
Transfer SUCCESS. actual_receive=17.20 USDT
```

`actual_receive` — сума, яку Gate повідомив як фактично зараховану. Відкрийте Gate і перевірте **Spot Account → USDT**. Для подальшого виведення на гаманець використовуйте звичайний інтерфейс Gate.

Якщо обмінювати нічого, але CROSSEX USDT вже є, програма одразу перейде до пропозиції переказу. Дуже дрібний залишок, менший за точність або мінімум Gate, може залишитися на CrossEx.

## Як відмовитися або зупинитися

На будь-яке запитання замість `YES` натисніть Enter. Це скасовує **саме запитану дію**: після відмови від обміну програма ще може запропонувати переказ уже наявних USDT.

Щоб завершити роботу повністю, натисніть **Ctrl+C**. Але закриття вікна або Ctrl+C **не скасовує запит, який уже відправлено Gate**. Після переривання обміну/переказу спочатку перевірте його результат у Gate.

## Що означають повідомлення

| Повідомлення | Що робити |
|---|---|
| `SKIP` | Для цього активу не знайдено маршруту, Gate відхилив котирування/суму або спрацював ліміт ціни. Дивіться текст причини; цей актив не обмінювався. |
| `STOP` | Подальші дії припинено. Прочитайте причину. Раніше підтверджені обміни не відкочуються. |
| `AMBIGUOUS` або `PENDING` | Операція могла бути прийнята, але остаточний результат не підтверджений. **Не повторюйте запуск одразу. Перевірте баланси та історію Gate.** |
| `Transfer FAIL` | Gate повернув кінцевий статус відмови. Скрипт не повторює цей запит. Перевірте причину й історію. |
| `403`, `INVALID_KEY`, помилка прав або часу | Перевірте відповідність Key/Secret, дозволи ключа, дозволену IP-адресу та системний час. Не публікуйте ключі разом із помилкою. |
| `Missing field`, `Invalid ... field` | Відповідь API не відповідає очікуваній структурі. Скрипт зупиняється, а не підставляє нуль або вигадує суму. |
| `file does not exist` | PowerShell не бачить файл за вказаним шляхом. Повторіть крок 2 та отримайте `True` від `Test-Path`. |

Після невизначеної фінансової операції немає автоматичного повторення. **Програма не веде постійного журналу, який захищав би від усіх ручних повторних запусків після закриття вікна або перезапуску ПК.** Перевірка Gate перед повторним запуском обов'язкова.

## Які залишки обробляються

Скрипт запитує пропозиції Gate для доступних non-USDT активів у `BINANCE`, `OKX`, `GATE`, `BYBIT`, `HYPERLIQUID`, `KRAKEN`. Це список кандидатів у програмі, **не гарантія підтримки кожної монети або суми**. Остаточну можливість обміну визначає відповідь Gate.

`DERIBIT`, невідомі акаунти та USDT поза `CROSSEX` не переводяться цим сценарієм: про них виводиться `SKIP`. Програма не дробить суми на частини і не підбирає обхідні маршрути автоматично.

Повторні запуски витрачають спільний денний ліміт Gate: документація вказує **100 запитів котирування на день**. Один обмін зазвичай потребує двох котирувань. Максимум програми — 40 кандидатів і до 80 quote-запитів за запуск; витрати інших програм та попередніх запусків вона не знає. Перевірка `-BalancesOnly` котирувань не запитує.

## PowerShell 7 та CMD

Для PowerShell 7 у рядку адреси Провідника введіть **`pwsh.exe`**. Перевірка балансу:

```powershell
pwsh.exe -NoProfile -ExecutionPolicy Bypass -File .\gate_crossex_cleaner.ps1 -BalancesOnly
```

Повний режим:

```powershell
pwsh.exe -NoProfile -ExecutionPolicy Bypass -File .\gate_crossex_cleaner.ps1
```

У CMD, відкритому в папці зі скриптом, працюють ті самі команди з **`powershell.exe`** з кроків 3–4. `-ExecutionPolicy Bypass` у цих командах стосується запущеного процесу, а не постійної зміни налаштувань Windows.
